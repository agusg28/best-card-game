ECLIPSE — Duel of Sun and Moon: a complete, original turn-based elemental card battler. You play Sol (gold sun) against the Luna AI (violet moon) on a deep indigo night-sky table — 30 life each, a mana curve from 1 to 10, Guard and Rush creatures, draw and heal combos, three AI difficulties (Easy/Normal/Hard with 1-ply lookahead), drag-and-drop or click controls, full keyboard play, a real strategic AI, fatigue when the deck runs dry, and genuine win and loss screens with an MVP card and final score. Vanilla JS and CSS only; it plays offline in a desktop browser.

## Run it

```sh
cd game && python3 -m http.server 8080
# then open http://localhost:8080/index.html
```
